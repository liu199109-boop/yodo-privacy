1. 我们是什么

YODO 是一款操作采集与技能生成工具，帮助用户把在浏览器中完成的可复用操作过程记录为结构化的 SKILL 文档。

2. 我们收集哪些数据

仅在用户主动点击"开始采集"后，且仅针对用户当时正在访问的页面：

  • 页面交互信息：点击、输入（密码字段不记录值）、选择、表单提交、页面导航、标签页切换；
  • 网络请求信息：页面发出的 Fetch/XHR 请求的 URL、方法、请求头（Authorization / Cookie / Token 等敏感头部的值会被掩码）、请求体与响应体（单条截断至 10KB）；
  • 剪贴板事件：用户在当前页面触发复制 / 剪切 / 粘贴时的内容；
  • 可选录屏：用户显式开启后，记录所选屏幕或窗口的画面，并按段保存；
  • 可选语音旁白：用户显式开启后，通过浏览器提供的 Web Speech API 将语音转写为文字并存入轨迹。语音识别由浏览器实现，音频可能由浏览器厂商按其隐私政策处理，我们仅保存转写后的文本；
  • 基础配置：用户填写或选择的会话名称、工号（选填）及界面偏好。
我们不收集：全局键盘输入（仅监听页面内表单输入事件）、与采集无关的浏览历史、精确位置、健康信息、金融账户信息。

3. 数据存储在哪里

  • 默认仅保存在用户本机的浏览器存储中（IndexedDB / chrome.storage.local），直到用户删除会话或卸载扩展；
  • 用户停止采集后，轨迹与可选的录屏分段会通过 HTTPS 自动上传至用户所属组织部署的 YODO 服务端用户所属组织部署的 YODO 服务端。该服务端的数据保留与删除遵循其所属组织的管理策略。

4. 我们如何使用数据

仅用于：还原用户的操作过程、建立操作与接口调用的关联、生成 SKILL 文档并供用户本人或其组织复用。不用于广告投放、用户画像、信用评估或任何与上述目的无关的用途。

5. 数据共享

  • 我们不会向任何第三方出售、出租或交易用户数据；
  • 除用户主动同步至其所属组织服务端外，不上传至任何公网第三方服务；
  • 不将数据用于判定信用度或贷款资格；
  • 仅在法律法规明确要求时，于必要范围内配合提供。

6. 敏感信息与安全措施

  • 密码字段不记录具体值；
  • Authorization、Cookie、Token、API Key 等头部值在存储前掩码；
  • 对 password / token / secret / apiKey / csrf 等敏感字段模式进行识别与标注；
  • 录屏与语音旁白默认关闭，需用户显式开启并授权；
  • 生成脚本中的凭证一律参数化，不以明文硬编码。

7. 用户权利

用户可随时：停止采集；查看、导出或删除单条 / 全部本地会话；卸载扩展（本地数据随之清除）；通过组织管理员或下方邮箱请求删除已同步至服务端的数据。

8. 儿童隐私

本扩展面向职场用户，不面向 16 岁以下儿童，也不会主动收集其数据。

9. 远程代码

本扩展不加载或执行远程代码。所有可执行代码均打包在扩展程序内。技能内容由服务端生成，仅作为文本或文件在扩展内展示与下载，从不求值执行。

10. 政策变更

政策更新将在本页面发布并更新生效日期；重大变更会通过扩展内提示或版本发布说明告知用户。

English

1. What YODO is

YODO helps users capture a reusable web workflow and turn it into a structured SKILL document.

2. Data we collect

Only after the user explicitly starts a capture, and only for the page(s) being used at that time:

  • Page interactions: clicks, inputs (password values are never stored), selections, form submissions, navigation, tab switches;
  • Network request data: URL, method, headers with Authorization / Cookie / Token values masked, and request/response bodies truncated to 10KB per record;
  • Clipboard events: content copied, cut or pasted by the user on the current page;
  • Optional screen recording: recording of a user-selected screen or window, stored in segments;
  • Optional voice narration: speech transcribed to text by the browser's Web Speech API. Recognition is performed by the browser; audio may be processed by the browser vendor under its own policy. We store only the transcript;
  • Basic settings: session name, optional staff ID, and UI preferences.
We do not collect: global keystrokes, unrelated browsing history, precise location, health information, or financial account information.

3. Where data is stored

When the user stops a capture, the trace and optional screen-recording segments are automatically uploaded over HTTPS to the YODO server deployed by the user's own organization only when the user explicitly requests SKILL generation or sync; retention on that server follows the organization's policies.

4. How we use data

Solely to reconstruct the captured workflow, correlate actions with API calls, and generate SKILL documents for the user and their organization. We do not use data for advertising, profiling, credit assessment, or any unrelated purpose.

5. Data sharing

We do not sell, rent, or trade user data. Apart from the user-initiated upload to their organization's server, no data is sent to any third party. Data is not used to determine creditworthiness or for lending purposes. We disclose data only when required by law.

6. Sensitive data and security

Password values are never stored; Authorization / Cookie / Token / API-key header values are masked before storage; sensitive field patterns (password, token, secret, apiKey, csrf) are detected and flagged; screen recording and voice narration are off by default and require explicit opt-in; credentials in generated scripts are always parameterized, never hard-coded.

7. Your rights

You may stop a capture at any time, view, export or delete any or all local sessions, uninstall the Extension to remove local data, and request deletion of server-side data through your organization administrator or the contact address below.

8. Children

The Extension is intended for professional users and is not directed to children under 16.

9. Remote code

The Extension does not load or execute remote code. All executable code is bundled in the extension package. Generated SKILL content is displayed and downloaded as text or files only, and is never evaluated.

10. Changes

Updates will be posted on this page with a new effective date; material changes will be communicated in-extension or in release notes.
